# JavaScript Learning Repository

A comprehensive collection of JavaScript learning materials, algorithms, interview preparations, and reference implementations. This repository serves as a structured knowledge base for mastering JavaScript from fundamentals to advanced concepts.

## 📁 Repository Structure

- **`algorithms/`**: Fundamental data structures and algorithms.
    - `Math`, `array`, `graph`, `hashtable`, `heap`, `linkedlist`, `queue`, `set`, `stack`, `tree`, `trie`.
- **`interview/`**: Common coding interview problems and their solutions, often including tests.
- **`projs/`**: Organized textbook examples (`Ch01` to `Ch22`) covering a wide range of JS and Web API topics.
- **`js5/` & `js7/`**: Version-specific exercises and feature demonstrations (ES5 and ES7+).
- **`java_oop/`**: Object-Oriented Programming concepts and Design Patterns implemented in JavaScript.
- **`array/`, `async/`, `bom/`, `func/`, `recursion/`, `scope/`**: Focused exercises on specific JavaScript language features.
- **`modules/`**: Examples of JavaScript module patterns.

## 🚀 Getting Started

### Running Scripts
Most files are standalone JavaScript scripts. You can run them using Node.js:
```bash
node path/to/file.js
```

### Running Tests
For files with accompanying tests (e.g., in the `interview/` folder):
```bash
node path/to/test.js
```

### Viewing HTML Examples
Files in the `projs/` and `js5/` directories often include `.html` files. Open these directly in any modern web browser to see the demonstrations in action.
