# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Common Commands

- Run a JavaScript file: `node <path/to/file.js>`
- Run a test file: `node <path/to/test.js>` (tests typically use the built-in `assert` module)

## Codebase Architecture

This repository is a comprehensive collection of JavaScript learning materials, exercises, and reference implementations. It is not a single application but a structured knowledge base.

### Directory Structure

- `algorithms/`: Implementations of fundamental data structures (Heap, Trie, Tree, Graph, etc.) and mathematical algorithms.
- `interview/`: Solutions to common coding interview problems, often including accompanying `.test.js` files.
- `projs/`: Large collection of textbook-style examples organized by chapter (`Ch01` through `Ch22`), containing both `.js` and `.htm` files.
- `js5/` & `js7/`: Exercises and examples specific to ES5 and ES7 features.
- `java_oop/`: Implementations of Object-Oriented Programming concepts and design patterns in JavaScript.
- `array/`, `async/`, `bom/`, `func/`, `recursion/`, `scope/`: Topic-specific exercises and demonstrations.
- `modules/`: Examples of modular JavaScript code.

The codebase primarily consists of standalone scripts and HTML files designed for educational purposes and individual execution.
